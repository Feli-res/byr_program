# 页面组件

| 位置 | 内容 |
| --- | --- |
| `forum/` | 论坛导航、列表、编辑、详情评论与版面管理 |
| `goods/` | 共用筛选、商品列表、发布编辑、详情管理及搜索 |
| `chat/` | 消息导航、会话列表、消息窗口、详情和通知 |
| `shared/content.js` | 读取错误、时间、分页及安全Markdown展示 |
| `auth.js`、`account-pages.js` | 原有身份、个人资料和账户页面 |
| `files.js`、`chat-contact.js`、`realtime.js` | 共用上传、联系卖家、实时连接与补读 |

`forum.js`、`goods.js`、`chat.js`只保留原页面导入入口，实际代码在对应子目录中，避免页面路径变化。列表读取共用`lib/use-data.js`：普通列表刷新时重新读取，聊天列表后台刷新时保留当前内容；切换账号或筛选时立即清除旧内容，迟到的请求不能覆盖新结果。
