# 验收共用方法

这里保存各场景共用的方法，不运行验收场景。导入包不会启动服务，也不会修改其他脚本的日志目录。

| 文件 | 内容 |
| --- | --- |
| `runtime.py` | 设置、启动停止、HTTP就绪检查和日志；每个实例传入自己的`log_dir` |
| `accounts.py` | 随机临时库、账号准备、SQL命令、管理员辅助及只清理自己的库 |
| `http.py` | 账户、文件/论坛及商品客户端；共用Cookie、CSRF、响应约定和请求失败处理 |
| `fixtures.py` | 合成图片和PDF，不使用真实用户附件 |
| `websocket.py` | 实时客户端、票据和事件格式验证 |
| `chat.py` | 通知样例与实时连接的准备和清理 |

`scripts/verify_*.py`各自只保留本阶段场景和报告入口。共用进程和数据库方法不依赖任何场景脚本；完整验收仍顺序运行，不并行争用开发端口。运行方式见 [脚本目录](../README.md)。
