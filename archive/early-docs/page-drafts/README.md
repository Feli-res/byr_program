更新日期：2026 年 10 月 23 日。范围：计划书 4.3 的页面和操作流程预览。

## 怎么打开

在资源管理器中进入 `D:\program_design_experiment\archive\early-docs\page-drafts`，双击 **[index.html](index.html)**，用 Edge、Chrome 等浏览器打开即可。无需启动服务、安装依赖或联网。建议一直从入口页内点击导航，方便在同一个页面中保留演示状态。

入口直接展示论坛帖子。右上角展开“草图工具”，可切换游客、普通用户、学习板块版主、管理员，以及正常、加载中、没有内容、加载失败和无权限状态。手机窄屏中通过导航按钮展开主菜单。

本次改版移除了宣传横幅、装饰英文和功能数量卡片；论坛改成紧凑的主题列表，商品、聊天和管理页面保留各自的结构。页面目录单独收纳，模拟标识继续保留。

已先从官方仓库下载 Noto Sans SC 中文字体，再本地应用。字号、配色、许可及下载记录见 [字体说明](assets/fonts/README.md)。无需联网加载字体。

## 建议按这条路线点一遍

1. 打开入口即可看到论坛，切换最新、热门或板块，进入帖子尝试回复、点赞和收藏。
2. 打开“二手集市”，筛选沙河商品，查看 iPad 详情，点击“联系卖家”。
3. 在聊天页输入示例文字，点击“发送示例消息”和“模拟对方回复”。
4. 打开“AI 搜索与匹配”，用默认 iPad 需求整理条件；修改预算和校区，再点击“按这些条件找商品”。
5. 确认条件后“保存商品提醒”，到任务页点击“模拟发布一件匹配商品”。
6. 打开通知中心查看新商品；重复模拟同一商品，不应产生重复通知。暂停该任务后再尝试。
7. 在个人中心查看自己的键盘商品，尝试编辑、预留或标记已售。
8. 展开“草图工具”，切换身份为管理员，再从账号菜单进入管理页；切换版主，查看管理范围变化。

## 草图的边界

- 页面所有人物、帖子、商品、价格、消息和状态均为示例，不代表真实交易或在线用户。
- 部分操作在浏览器允许时用 `localStorage` 保存本机演示数据；不同浏览器及本地文件地址的保存行为可能不同，不作为正式持久化。“草图工具”内的“重置本机演示数据”可恢复初始示例。本次改版使用新的示例数据版本，没有删除旧版本本机数据。
- 登录表单不验证真实身份，不发送、不保存密码；请选择虚构账号和密码。“草图工具”内的身份切换仅用于看不同界面，不是正式权限机制。
- “AI 理解”使用有限的本地固定规则示意，商品结果按硬条件筛选；没有调用模型、向量检索或后台调度，也不展示虚构匹配率。定时提醒由按钮手动模拟。
- 图片只在当前表单页预览，不上传、不跨页保存；商品详情继续使用示意插画。文件大小和浏览器类型检查不代替正式后端内容校验。
- 管理操作只影响示例数据；没有跨用户会话、账户封禁联动、消息同步或正式审计。页面是后续讨论和开发的参考。

当前已做 JavaScript 语法、静态链接和本地 DOM 交互检查，结果见 [qa-result.json](qa-result.json)。内置预览浏览器禁止打开 `file://`，未完成实际浏览器截图及设备兼容性验证；请按入口在本机浏览器确认显示效果。
