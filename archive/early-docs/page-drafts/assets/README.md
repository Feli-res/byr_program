# assets · 页面共用样式和交互

| 文件 | 用途 |
| --- | --- |
| [style.css](style.css) | 颜色、布局、导航、表单、卡片、对话框，以及窄屏显示规则 |
| [app.js](app.js) | 页面内容、示例数据、地址切换、筛选和本机模拟操作 |
| [fonts/](fonts/README.md) | 已下载的 Noto Sans SC 中文字体、内嵌字体 CSS、官方许可及来源记录 |

所有 HTML 引用本地字体 CSS、界面样式及脚本，不使用在线字体、外部图片或第三方服务。JavaScript 使用普通脚本加载，双击 HTML 即可运行，无需构建。正文字体 14px，帖子阅读正文 16px，辅助信息 12px。

图标和商品示意图由代码中的内嵌 SVG 绘制；商品实际图片只在选择文件后于当前表单中预览。返回 [页面目录与操作说明](../README.md)。
