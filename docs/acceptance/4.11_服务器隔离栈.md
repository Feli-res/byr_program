edge → API/web；API → 独立 MySQL/Redis/embedding；所有命名卷属于 `youzhihui-411`。不复用 trial 数据卷。网页 Origin 固定为 `http://localhost:18093`，后续浏览器应通过 SSH 隧道用这个地址访问。

以下命令供后续明确启动时使用，本次未执行最终配置的启动或压测：

```sh
cd /home/sunxiang/youzhihui/acceptance411
# 先确认可用内存至少 3584 MiB、端口空闲。
free -m
docker compose --env-file .env.411 -f compose.411.yaml -p youzhihui-411 config --quiet
docker compose --env-file .env.411 -f compose.411.yaml -p youzhihui-411 up -d --no-build
# 查看实际限制和健康状态
docker stats --no-stream
docker compose --env-file .env.411 -f compose.411.yaml -p youzhihui-411 ps -a
# 停止并保留数据
docker compose --env-file .env.411 -f compose.411.yaml -p youzhihui-411 stop
```

不使用全局容器/卷清理；删除测试数据须另行明确执行，只能针对 411 项目。准备阶段不删除数据卷。
