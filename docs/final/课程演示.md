# 课程验收演示

建议准备两个独立浏览器会话和一个管理员会话。网址：<https://youzhihui.85-121-122-124.sslip.io>。专用买卖账号及密码在本机 `.local/final412-02/演示账号.md`；管理员凭据使用负责人已有的私密记录。不要投屏密码文件。

演示资料均标记“课程验收412”，不代表真实商品。预备检查留下的商品已售、提醒已暂停；现场需要另发一件在售商品并新建提醒，不能用已售商品说明匹配成功。

| 顺序 | 操作和讲解 | 必须看到的结果 |
| --- | --- | --- |
| 1 | 买家注册一个新账号，或展示已有专用账号登录 | 自主注册；不宣称校园身份已认证 |
| 2 | 卖家在论坛发布带图帖子，买家回复并搜索 | 刷新后仍可读取帖子、评论与图片 |
| 3 | 卖家发布学习平板，价格 1800 元，沙河校区，填写真实条件 | 商品详情、图片及价格校区正确 |
| 4 | 买家输入“2000元以内、沙河校区交易的二手平板，用来记笔记” | AI 整理条件，用户可确认或修改；预算降至 1000 元后排除该商品 |
| 5 | 恢复 2000 元预算，保存五分钟商品提醒 | 任务显示条件、状态、最近及下次检查时间 |
| 6 | 先等首轮完成，再发布另一件符合条件的商品 | 到下一轮出现一次站内通知；等待时间最长按周期加两分钟预留 |
| 7 | 买家打开通知、联系卖家，两窗口收发文字并刷新 | 实时消息可见、历史仍在，未登录会话无法读私聊 |
| 8 | 买家尝试编辑卖家帖子，卖家将商品标记已售 | 越权被拒绝；已售商品不再成为有效 AI 匹配 |
| 9 | 暂停提醒再发布匹配商品，展示完整周期观察记录 | 不产生新提醒，原通知不重复 |
| 10 | 用自建帖子提交测试举报；管理员查看并驳回，发布再撤回临时公告 | 举报人能读取处理结果；草稿和撤回公告不公开 |
| 11 | 展示项目容器重启后的读取及独立恢复记录 | 记录必须来自真实运行，尚未执行的项目直接说明未完成 |

AI 暂时不可用时，展示错误提示和手动条件确认，继续普通搜索；不能把手动筛选描述成 AI 理解成功。现场若网络中断，可展示已保存的真实 JSON 和页面截图，明确这是此前记录。
