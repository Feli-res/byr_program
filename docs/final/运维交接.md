## 常见问题

网站打不开：先检查 DNS/HTTPS、前端和 API 的状态，区分入口故障与程序故障；不得为本项目重启整台共享服务器或其他人的服务。健康检查正常仍需操作页面，不能用 readiness 替代全流程。

AI 理解失败：核对服务器 `AI_ENABLED`、外部服务额度与相关日志。密钥只保存在服务器私密配置，浏览器不应出现。AI 超时后使用手动条件；语义服务不可用时页面应说明降级，普通关键词筛选继续使用。

没收到提醒：检查账号是否封禁、任务是否暂停或异常、下次检查时间、商品是否在售、预算校区条件是否符合。周期最短五分钟，已提醒过的商品不会因编辑条件再次通知；不要直接在试用库改任务时间来演示。

图片不可访问：先确认内容未删除、隐藏或下架，检查文件绑定和权限，再核对上传卷。不可将私密目录整体映射到公开 Web 路径。

更新失败：保留新版本日志、旧版本路径和更新前配套备份。已发生数据库迁移时，不能仅切换旧代码就认定回滚完成；先在独立环境验证备份对应的版本与资料，不直接覆盖试用数据。

备份失败：检查磁盘、锁、容器状态和计时器日志。只有包含所有文件并通过 `SHA256SUMS` 的快照才可使用；新版 inventory 还要经过独立恢复核对。自动异地同步仍未配置，手动下载不能写成已实现自动同步。
