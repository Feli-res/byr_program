# 4.10 管理页面与功能联动

更新日期：2026 年 10 月 31 日。状态：**本机实现与验收完成，试用站已更新至 `trial-20261031-02`**。

本阶段把原来只支持帖子的举报扩展为帖子、评论、商品、私信四类，补齐公告、板块、提醒任务和操作记录管理页，并实际检查每个管理动作在论坛、搜索、聊天和提醒中的结果。

## 使用

管理员登录后从顶部“管理”进入 `/admin` 概览；版主只看到帖子管理和举报处理。

| 页面 | 用途 |
| --- | --- |
| `/admin` | 管理概览与待处理举报数量 |
| `/admin/users` | 角色、板块授权、封禁和密码重置 |
| `/admin/boards` | 新建板块、修改名称/说明、启用或停用 |
| `/admin/posts` | 置顶、隐藏、恢复帖子和评论 |
| `/admin/goods` | 下架违规商品或解除限制 |
| `/admin/reports` | 按类型/状态/板块查看并裁定举报 |
| `/admin/announcements` | 创建草稿、发布、撤回公告 |
| `/admin/subscriptions` | 查看脱敏任务信息并暂停异常任务 |
| `/admin/audit-logs` | 查看操作者、动作、对象、原因和结果 |

普通用户在帖子评论、商品详情和收到的私信旁可以举报；在“我的举报”查看处理结果。首页和 `/announcements` 只显示已发布公告。

### 举报处理规则

| 类型 | 管理员操作 | 同一事务内的联动 |
| --- | --- | --- |
| 帖子 | 成立并隐藏 / 成立不隐藏 / 不成立 | 隐藏后详情和旧地址返回不可用，关键词与语义搜索均排除 |
| 评论 | 成立并隐藏 / 成立不隐藏 / 不成立 | 评论正文不再返回，帖子详情只显示“已隐藏”占位 |
| 商品 | 成立并下架 / 成立不处理 / 不成立 | 商品转下架并受限制，搜索、AI 匹配和提醒不再接受，卖家收到说明 |
| 私信 | 成立 / 不成立 | 不修改消息；只给举报人结果，管理员只看到被举报消息及此前最多 4 条，不提供整段会话 |

- 帖子/评论举报：管理员和该板块版主可处理；版主不能跨板块。
- 商品/私信举报：仅管理员；私信不进入外部 AI 分析。
- 重复提交同一目标的待处理举报会返回已有编号。
- 处理检查举报版本和目标版本；内容已被他人修改时返回版本冲突，需重新读取。
- 所有处理写审计记录，`safe_changes` 只存动作和状态，不存私信正文或用户私人条件。

### 公告与板块

- 公告状态为草稿 → 已发布 → 已撤回；草稿和撤回内容公开接口一律 404。
- 已发布公告修改前必须先撤回；发布和撤回必须填写原因。
- 板块停用后不能新发帖，历史公开帖仍可读；不删除历史数据。

## 运行与边界

- 不新增数据库迁移，沿用 `0001—0007` 已建的 `reports`、`announcements`、`boards`、`audit_logs` 等表。
- 新举报入口为 `POST /api/v1/reports`；旧 `POST /api/v1/post-reports` 保留兼容。
- 公告不进入全站搜索；未发布公告不会被搜索到。
- 私信举报只展示必要上下文，管理员仍不能浏览整段私聊。
- 4.10 的本机验收不代表 4.11 的 AI 效果对比、多人负载或 4.12 的独立备份恢复已经完成。
