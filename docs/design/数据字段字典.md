# 数据字段字典

字段取自 [schema.sql](schema.sql)，含义与关系见 [02_数据与关系.md](02_数据与关系.md)。本文件由 `check_design.py` 提取，类型与空值以SQL为准，业务校验还需遵守页面/接口/状态说明。

共有 32 张表。`id` 为内部编号；`created_at/updated_at` 为UTC时间；`version/config_version` 用于防止旧页面覆盖新数据。
