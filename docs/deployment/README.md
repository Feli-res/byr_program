# 4.7 基础功能试用部署

网站：<https://youzhihui.85-121-122-124.sslip.io>。日常操作见 [服务器使用说明](../../邮智汇_服务器使用说明.md)。

## 本次增加的内容

- 独立 Docker Compose：Next.js、Rust API、MySQL、Redis与持久数据卷。
- 新增 Nginx 站点和 HTTPS 证书，数据库与 Redis 不向公网映射。
- 后端仅在网关密钥正确时采用网关提供的单个访客 IP；网关覆盖外部同名头，防止伪造来源绕过限制。
- 关闭开发接口和页面入口，启用安全 Cookie、来源校验和 WSS。
- 新建服务器数据库与专用管理员，本机账户、资料和上传文件保留。
- 启动、停止、日志、更新前备份、每日备份、旧版本保留和本机异地副本。

## 修复与核对

首次检查发现上传卷由 root 创建，非 root API 进程无法写入。已修正镜像中上传目录的所有权，并调整首次创建的数据卷；随后图片、PDF及浏览器上传检查通过。

验收用图片曾误用与图像尺寸不符的样本，已改用合法样本；通知检查曾把框架的空提示节点当成错误，现改为检查实际通知标题和空列表。部分 Python 请求受本机 HTTP 代理中断影响，权限复验改为直连真实 HTTPS 站点。以上检查脚本问题没有放宽产品权限或校验。
